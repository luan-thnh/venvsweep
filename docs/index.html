01 / Built for messy Python workspaces

Your env folder doesn't have to be called .venv.

VenvSweep starts with sensible defaults, then lets every team or developer add the folder names they actually use.

⌕

Auto-detect common virtual environments

Scan from the current directory or choose a root folder. Detect .venv and venv out of the box, with room for project-specific names.

.venv venv .my-venv env-py312 backend-env
↯

See the storage cost first

Surface environment size, path, Python version, and recency so old 2 GB environments stop hiding inside forgotten side projects.

⌨

Keyboard-first

Move with arrows or j/k, toggle items with Space, select all with A, then confirm once.

⌁

Pick the scan root

Start where you are, pass a directory flag, or interactively choose a projects folder.

◌

Fast re-creation mindset

Only target regenerable virtual environments. Keep source files and project manifests untouched.

02 / Three steps

Scan. Select. Sweep.

Minimal commands, visible consequences, and no need to manually crawl every repository.

01

Choose where to look

Run in the current folder or point VenvSweep at a workspace containing many Python projects.

02

Review the candidates

Sort or filter the detected environments, then use Space to build your cleanup selection.

03

Confirm the removal

Press Enter, review the total reclaimable storage, and confirm before anything is deleted.

1# scan the current folder
2npx venvsweep

03 / Deletion needs guardrails

Fast cleanup shouldn't mean reckless cleanup.

✓

Explicit selection

No environment is removed just because it was found. VenvSweep makes the user select candidates first and shows the total space before confirmation.

◎

Dry-run friendly

Add a preview mode for scripts and CI, plus exclusions for directories that should never be traversed or deleted.
